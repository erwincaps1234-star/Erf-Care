Report & Backup

Kasama sa report ang Item Description, Qty at Consignee Name para sa bawat waybill. I-import ang order CSV sa ibaba para ma-populate ang mga detalye.

CSV ang pinakamadaling format para sa Excel at Google Sheets. Puwede itong i-download sa cellphone at i-attach sa email.

Import order list CSV

Ihanda ang CSV na may columns na waybill, item description, qty, consignee. Puwede rin ang headers na tracking number, item, quantity, recipient. Import ito para awtomatikong maitugma ang detalye kapag nag-scan.

Paalala: walang awtomatikong access ang app sa Shopee/Lazada/TikTok orders. Kailangan ng order CSV o manual entry para makuha ang item description, qty at consignee. Ang clear ay hindi na maibabalik.
